# Kaspi Seller Analytics — тестовый backend

FastAPI-сервер с генерируемыми данными магазина на Kaspi: 49 товаров, 5 категорий, 180 дней заказов,
конкуренты на карточках, история цен, рейтинги и остатки. Данные одинаковые при каждом запуске (`SEED` в `app/config.py`),
даты всегда заканчиваются сегодняшним днём.

## Запуск

```bash
uv sync
uv run uvicorn app.main:app --reload --port 8000
```

- Документация API: http://localhost:8000/docs
- Тесты: `uv run pytest`

## Эндпоинты

Параметры периода: `?from=YYYY-MM-DD&to=YYYY-MM-DD` (по умолчанию — последние 7 дней). Деньги — целые ₸.

**Внутренняя аналитика**

| Метод | Что отдаёт |
|---|---|
| `GET /api/summary` | KPI за период и изменение к прошлому периоду той же длины |
| `GET /api/breakdown` | Куда уходит цена: комиссия, доставка, штрафы, себестоимость, налог, прибыль |
| `GET /api/sales/daily` | Продажи, выплаты и прибыль по дням |
| `GET /api/products` | Товары с юнит-экономикой, ABC, позицией цены и остатком. Фильтры: `category`, `search`, `abc`, `sort`, `order` |
| `GET /api/products/{id}` | Карточка товара: экономика единицы и продажи по дням |
| `GET /api/stock` | Остатки, скорость продаж за 14 дней, дней до нуля, ожидаемые поставки |
| `GET /api/categories` | Категории и комиссии |
| `GET /api/settings` | Ставки расчёта и границы данных |

**Внешняя аналитика**

| Метод | Что отдаёт |
|---|---|
| `GET /api/market/products/{id}/offers` | Все продавцы на карточке, моё место, отрыв от минимальной цены |
| `GET /api/market/products/{id}/history` | Моя / мин. / средняя / макс. цена, рейтинг и отзывы по дням |
| `GET /api/market/categories` | Индекс цены к рынку, доля товаров, где я самый дешёвый |
| `GET /api/market/alerts` | Сигналы: конкурент подрезал цену, потеря первой позиции, падение рейтинга, остатки. Фильтр `severity` |

## Структура

```
app/
  config.py          ставки комиссий, доставки, налога, CORS
  data/              генератор тестовых данных и модели
  services/          расчёты: internal (магазин), market (рынок), alerts (сигналы)
  routers/           HTTP-эндпоинты
  schemas.py         контракт ответов (по нему будет строиться React)
tests/               проверки, что цифры сходятся между эндпоинтами
```

Ставки в `config.py` — заглушки. Перед подключением реального магазина сверьте их с тарифами Kaspi и своим налоговым режимом.
При переходе на реальные данные меняется только слой `data/`, контракт API остаётся прежним.
