# Аналитика продавца Kaspi

- `backend/` — Python (FastAPI) сервер с тестовыми данными. Подробности — в [backend/README.md](backend/README.md).
- `web/` — React-сайт (Vite + TypeScript + Tailwind + TanStack Query + Recharts).

## Запуск (два терминала)

```bash
cd backend
uv run uvicorn app.main:app --reload --port 8000
```

```bash
cd web
npm install
npm run dev
```

Сайт: http://localhost:5173. Запросы `/api` Vite перенаправляет на порт 8000.

## Страницы

| Адрес | Что показывает |
|---|---|
| `/niches` | Подбор ниш: товары-кандидаты вводятся вручную, сайт считает экономику и оценку 0–100 |
| `/calculator` | Калькулятор: прибыль с одной продажи по тарифам Kaspi, цена без убытка и цена для нужной маржи |
| `/` | Обзор: выручка, удержания Kaspi, выплаты, прибыль, куда уходит цена, продажи по дням, топ товаров, сигналы |
| `/products` | Таблица товаров: ABC, цена и место на карточке, продажи, прибыль, маржа, остаток. Поиск, фильтры, сортировка |
| `/products/:id` | Карточка товара: продажи, экономика 1 шт, история цен против конкурентов, продавцы на карточке |
| `/market` | Рынок по категориям (индекс цены, где вы самый дешёвый) и лента сигналов |
| `/stock` | Остатки: на сколько дней хватит, ожидаемые поставки |

Период выбирается сверху и хранится в адресе страницы (`?from=…&to=…`), поэтому ссылкой можно поделиться.

Обзор, Товары, Рынок и Остатки пока работают на вымышленных данных. Подбор ниш и калькулятор используют настоящие тарифы Kaspi
(`backend/app/tariffs.py`, там же источники и дата проверки), а кандидаты хранятся в локальном файле `backend/storage/app.db`, который не попадает в git.

Автоматический сбор данных с Kaspi запрещён пунктом 13.1 Пользовательского соглашения, поэтому цифры с карточек вносятся вручную.
