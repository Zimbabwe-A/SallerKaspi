# Ночной анализ 03:00–06:00 — план

Цель: раздел «Что закупать нового» в «Аналитике рынка». Тяжёлые проверки идут ночью, когда Kaspi меньше нагружен
и сайт никому не мешает. Всё — только чтение открытых страниц kaspi.kz, без обхода защит: если Kaspi ограничивает
запросы, ночь останавливается и продолжает завтра.

## Где и как запускается

- Тот же процесс `python -m app.kaspi.autoupdate`: днём — каждые 5 минут (заказы, конкуренты, бот),
  ночью, один раз за ночь в окне 03:00–06:00, — ночной анализ. Если к 06:00 не успел — останавливается, утром дневной режим.
- Mac должен не спать ночью: вариант А — оставить включённым с зарядкой и запретить сон
  (`caffeinate` на время окна); вариант Б (надёжнее) — небольшой сервер в Казахстане, ≈2–5 тыс. ₸/мес.
- Темп: не больше 1 запроса в 1–2 секунды. За 3 часа это ≈5–10 тыс. запросов — хватает на всё ниже.
- Результаты: `backend/var/shops/main/night/<дата>.json`; сайт показывает последнюю ночь и «обновлено в 05:12».

## 1. Новички-взлёты (первым — данных больше всего)

Что: карточки, появившиеся меньше месяца назад, которые уже много продают.

Как:
1. Ночью обходим ваши категории и соседние (берём из ваших товаров `category_code`) — список карточек, сортировка
   «новинки» и «популярные», первые 5–10 страниц.
2. Для каждой карточки записываем: код, цену, число отзывов, рейтинг, число продавцов, дату первого появления у нас.
3. Каждую ночь сравниваем с прошлыми: прирост отзывов за 7 дней ≈ продажи (на Kaspi отзыв оставляют примерно
   5–10% покупателей — коэффициент подберём по вашим же товарам, где мы знаем и продажи, и отзывы).
4. «Взлёт» = карточке < 30 дней и прирост отзывов в топ-10% категории.

На сайте: список «Новички-взлёты» — товар, категория, сколько дней на рынке, ≈продаж в неделю, продавцов, цена,
кнопка «Открыть на Kaspi».

Первые результаты: через 7 ночей (нужна история для прироста).

## 2. Поисковые магниты (ищут, но не находят)

Честно: настоящих поисковых запросов покупателей Kaspi продавцам не отдаёт. Делаем приближение:
1. Список запросов-кандидатов: названия ваших товаров и их вариации, подсказки поиска kaspi.kz
   (автодополнение по первым буквам — это то, что люди реально часто вводят), тренды из п. 3.
2. Ночью проверяем каждый запрос в поиске kaspi.kz: сколько найдено карточек и сколько у них продавцов.
3. «Магнит» = запрос есть в подсказках (значит, его ищут), но карточек 0–2 или все без продавцов.

На сайте: «Ищут, но почти нет предложений» — запрос, сколько карточек, сколько продавцов, ссылка на поиск.

Первые результаты: после первой ночи.

## 3. Тренды соцсетей (TikTok / Instagram)

Честно: открытых данных о вирусности у TikTok и Instagram для такого анализа нет
(их API дают статистику только по своим аккаунтам; TikTok Research API — для исследователей).
Варианты по возрастанию цены:
1. Google Trends по Казахстану (бесплатно): рост интереса к названию товара/бренда за 30 дней.
2. Вы подписываете нужные аккаунты/хэштеги, а мы раз в ночь смотрим их открытые публикации — только если это
   разрешено правилами площадки; иначе не делаем.
3. Платный сервис аналитики соцсетей с официальным API (≈ от 20–50 тыс. ₸/мес) — если тренды окажутся важны.

Предлагаем начать с варианта 1 и решить про 2–3 позже.

## Порядок работ

| Шаг | Что | Результат |
|---|---|---|
| 1 | Ночное окно в автообновлении + запись результатов | Ночь отрабатывает и пишет журнал |
| 2 | Новички-взлёты: обход категорий и история отзывов | Список через 7 ночей |
| 3 | Поисковые магниты: подсказки поиска + проверка выдачи | Список после 1-й ночи |
| 4 | Google Trends по товарам и брендам | Сигнал «спрос растёт» |
| 5 | Вкладка «Что закупать нового» на сайте | Три списка с датой обновления |

Ничего из этого не меняет магазин: только чтение открытых страниц kaspi.kz.
